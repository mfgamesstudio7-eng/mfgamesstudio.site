MF GAMES STUDIO — GITHUB PAGES WEBSITE

1. Create a GitHub repository.
2. Upload the CONTENTS of this ZIP (not the enclosing folder) to the repository root.
3. In Settings > Pages, choose Deploy from a branch, main, /(root).
4. In Settings > Pages > Custom domain, enter mfgamesstudio.site.
5. Set the DNS A records for @ to GitHub Pages IPs: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
6. Optional: www CNAME -> YOUR-GITHUB-USERNAME.github.io (replace with your actual username).
7. Wait for DNS verification and enable Enforce HTTPS when available.
8. Create contact@mfgamesstudio.site in Zoho before using the contact email publicly.
9. Review the privacy policy and update it to match your actual practices. It covers this WEBSITE, not your game SDK data handling.
